### **3. Cryptography & Security (The Zero-Knowledge Pipeline)**
* **Bcrypt vs. CryptoJS Tag-Team:**
    * *Function:* Uses Bcrypt on the backend to *hash* the Master Password (for login authentication), and CryptoJS on the frontend to *encrypt/decrypt* the vault passwords (so the server never sees them).
* **The Zero-Knowledge Paradox & Emergency Recovery Key:**
    * *Function:* Replaces the vulnerable "Forgot Password" email system with a hardcoded 16-character backup key to maintain true zero-knowledge security.
* **The "Brutal Wipe" Penalty:**
    * *Function:* If an operative uses their Emergency Recovery Key to reset their Master Password, the system wipes their vault clean to ensure their previously encrypted data cannot be compromised.

### **4. Backend Logic & Access Control (The Server)**
* **The Vaporize Route (`DELETE /api/vault/:id`):**
    * *Function:* Fixed the `404 Not Found` error by wiring up the proper controller logic to permanently erase a credential from the MongoDB cloud.
* **Tenant Isolation (User ID Tagging):**
    * *Function:* Patches a critical security flaw by attaching an Operative's MongoDB `_id` to every password they save, ensuring they can only fetch and delete their own loot, not anyone else's.
* **Commander Admin System (RBAC):**
    * *Function:* Upgrades the database schema with a `role: 'operative' | 'commander'` system, allowing specific users (like yourself) to access a protected Admin Dashboard to manage user privileges.
